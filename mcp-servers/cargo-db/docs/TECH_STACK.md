# Tech Stack

- **Python 3.11+**: Core execution language.
- **mcp**: Official Model Context Protocol SDK for Python for `stdio` server bindings.
- **SQLAlchemy 2.x**: Abstracted DBMS interaction supporting broad multi-engine availability.
- **Database Drivers**: `psycopg2-binary` (PostgreSQL), `pymysql` (MySQL). SQLite is built-in.
